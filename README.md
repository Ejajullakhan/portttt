# Zovo Agency

A clean, multi-page static agency website for a web development studio.

## Pages
- `/` — Home
- `/services` — Services
- `/work` — Selected work
- `/about` — About
- `/contact` — Contact

## Notes
- Portfolio links open the live project in a new tab.
- Contact form is demo-only and needs a real form/email endpoint before launch.
- No framework or build step is required.
